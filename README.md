# projectt
1. 프로젝트 소개

프레임렌즈 스튜디오는 현대 사회에서 필수가 된 미디어 리터러시 역량을 쉽고 재미있게 기를 수 있도록 기획·개발한 웹 기반 플랫폼이다. 단순히 글을 읽고 주입식으로 배우는 방식에서 벗어나, 1980~90년대 오락실 감성의 블랙/네온 다크 아케이드 UI와 갈무리 픽셀 폰트 디자인을 적용하여 사용자가 자연스럽고 흥미롭게 몰입할 수 있도록 만들었다. 인공지능 기술을 활용해 미디어를 비판적으로 수용하고 분석하는 힘을 길러주는 것을 목표로 한다.



2. 주요 기능 설명

프레임렌즈 스튜디오의 주요 기능은 크게 메인 화면과 채팅 화면으로 나뉘어 구성되어 있다. 먼저 메인 화면에서는 네이버 검색 API를 연동하여 최신 뉴스 기사를 빠르고 직관적으로 검색할 수 있으며, 제미나이 및 이미지 생성 모델을 활용해 검색한 뉴스 주제를 바탕으로 맞춤형 뉴스 포스터, 만화, 인포그래픽 등의 콘텐츠를 직접 만들어볼 수 있다. 다음으로 채팅 화면에서는 실시간 시사 및 뉴스 상식을 활용해 인공지능과 대결하거나 추리하는 아케이드 게임을 즐길 수 있다. 여기에는 실시간 네이버 뉴스 기사 브리핑을 바탕으로 4명의 인공지능 용의자 증언을 분석하여 교묘하게 왜곡된 가짜 뉴스를 퍼트린 스파이를 찾아내는 '뉴스 내용 스파이 찾기' 추리 게임이 포함되며, 게임 종료 후 상세한 팩트체크 해설을 제공하여 미디어 비판적 사고를 돕는다. 또한 인공지능 쇼 호스트와 함께 실시간으로 경제, 사회, 기술, 인공지능 등 시사 관련 단어를 이어가는 '뉴스 키워드 쿵쿵따' 퀴즈 게임도 함께 즐길 수 있다



main.py 이용법
1. 관심 키워드 검색하기: 프레임렌즈 스튜디오에 접속한 뒤 메인 화면에 있는 검색창에 평소 관심이 있었거나 흥미롭게 보았던 시사 및 뉴스 키워드를 직접 입력한다.

2. 뉴스 기사 선택하기: 검색 결과로 나타난 최신 뉴스 목록 중에서 콘텐츠로 제작하고 싶은 기사를 하나 선택한다.

3. 미디어 콘텐츠 생성하기: 선택한 기사를 바탕으로 제공되는 여러 미디어 생성 옵션(뉴스 포스터, 만화, 인포그래픽 등) 중 원하는 형식을 고르고 생성 버튼을 누른다.

4. 결과물 확인 및 저장하기: 인공지능이 기사 내용을 분석하여 제작해 준 맞춤형 이미지가 화면에 나타나면, 마음에 드는 결과물이 완성되었을 때 이미지를 다운로드하여 저장한다



나. chat.py 이용 방법

1. 아케이드 모드 진입하기: 사이드바나 메뉴를 통해 채팅 화면(아케이드 모드)으로 이동하면, '뉴스 내용 스파이 찾기'와 '뉴스 키워드 쿵쿵따' 중 원하는 미니게임을 선택할 수 있는 로비 화면이 나타난다.

2. 뉴스 내용 스파이 찾기 플레이하기:

글머리기호 게임 시작 버튼을 누르면 실시간 네이버 뉴스 기사와 4명의 인공지능 용의자가 소집된다.

글머리기호 상단에 제공되는 뉴스 브리핑 내용과 원문 링크를 참고하면서, 용의자들이 대화창에 남기는 증언 메시지들을 꼼꼼히 읽어본다.

글머리기호 용의자들의 발언 중 어느 부분이 뉴스 내용과 다른지 추리하고, 채팅창에 자신의 의견을 입력하거나 투표 기능을 이용해 교묘하게 거짓말을 하고 있는 스파이를 지목하여 처형한다.

글머리기호 게임이 끝나면 제공되는 상세한 팩트체크 해설을 읽으며 진실을 확인하고 점수를 얻는다.

1. 뉴스 키워드 쿵쿵따 플레이하기:

글머리기호 쿵쿵따 게임을 선택하면 인공지능 쇼 호스트가 첫 제시어와 끝 글자를 알려준다.

화면 아래에 있는 입력창에 제시어의 마지막 글자로 시작하는 경제, 사회, 기술, 인공지능 등의 시사 관련 단어를 입력하여 전송한다.

인공지능 파트너가 단어의 정답 여부와 시사 연관성을 판정해주며, 연속으로 성공할 경우 점수가 올라가고 새로운 단어로 게임이 계속 이어진다.
